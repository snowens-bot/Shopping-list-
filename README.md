# Shopping list

A phone-friendly shopping list and weekly meal plan. It works offline, and everything stays in this browser — there is no account and no server.

Once GitHub Pages is on, open it at <https://snowens-bot.github.io/Shopping-list/>.

## Turn on GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Set the branch to **main** and the folder to **/ (root)**.
5. Save. The site usually appears within a couple of minutes.

The app is plain HTML, CSS, and JavaScript in the root of the repository, so there is no build step.

## Add it to your home screen

Open the site once while you are online so it can be saved for offline use. After that, add it to your home screen. It uses the shopping-basket icon and opens full screen.

### iPhone

1. Open the site in **Safari**.
2. Tap the **Share** button.
3. Tap **Add to Home Screen**.
4. Tap **Add**.

### Android

1. Open the site in **Chrome**.
2. Tap the menu (three dots).
3. Tap **Install app** or **Add to Home screen**.
4. Confirm.

## Using it

- Items are grouped under Chilled, Frozen, Veg, Store cupboard, and Home.
- Tesco, Waitrose, and M&S are always there. Type another shop to remember it, and remove shops you added yourself.
- Filter by shop so you only see that shop’s items while you are there.
- Tap an item to tick it off. Ticked items move to the bottom. Edit an item to change or delete it, then use **Clear ticked items** when you are done with them.
- **Meals** is Monday to Sunday, with lunch and dinner. Tap **+** beside a meal to add its ingredients to the list. **Clear week** empties the plan.
